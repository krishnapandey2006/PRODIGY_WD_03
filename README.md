# PRODIGY_WD_03 — Tic-Tac-Toe (Polished)
**Task 03** for Prodigy InfoTech Web Development Internship (December 2025)

## Live Demo
https://krishnapandey2006.github.io/PRODIGY_WD_03/

## Features
- Play 2-player or vs AI
- Easy (random) and Hard (Minimax optimal) AI difficulty
- Scoreboard with localStorage persistence
- Accessible and responsive UI with animations
- New game and Reset score controls

## Tech
- HTML5, CSS3, Vanilla JavaScript (no libs)

## How to run locally
1. `git clone https://github.com/krishnapandey2006/PRODIGY_WD_03.git`
2. `cd PRODIGY_WD_03`
3. Open `index.html` in the browser or run `npx http-server`
